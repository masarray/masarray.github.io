# Support

## Portal support

Open an issue in this repository for problems with:

- the main MasArray landing page;
- a missing, duplicated, or incorrectly categorized public repository;
- broken portal navigation, search, filters, themes, or responsive layout;
- incorrect portal-level copy or metadata;
- accessibility, performance, SEO, or browser compatibility of this website.

Use the structured issue forms at:

`https://github.com/masarray/masarray.github.io/issues/new/choose`

## Product support

For installation, device communication, protocol behavior, audio processing, licensing, releases, or a bug inside a specific application, use that application's repository and support documentation. Include the product name, version, platform, release asset, and reproducible steps.

The portal is a directory and does not provide a universal support contract for every linked project.

## Information that must stay private

Do not publish:

- customer or employer files;
- SCL, PCAP, COMTRADE, IO lists, relay settings, IP plans, or screenshots containing confidential project data;
- activation codes, request IDs, order records, credentials, tokens, or private keys;
- personal data or private audio/video;
- undisclosed security vulnerabilities.

Sanitize examples before posting. Use the private security channel described in [`SECURITY.md`](SECURITY.md) for vulnerabilities.
